# 前台设计说明

## 目标与视觉

公开展示海运时效，帮助客户从柜子、航线、亚马逊仓库三个角度筛选和对比。采用横向导航，减少内部管理系统的操作感。深海蓝承接 Logo 的品牌色，青绿表示物流进程，金色辅助区分仓库视角。

原始 Logo 保存在 `public/zhhq_logo-source.png`，品牌标志裁切为 `public/brand-mark.png`，未重绘或变更标志比例。字体本地打包，中文使用系统中文字体。图标来自 Ant Design Icons，数据图表来自 Recharts。

## 首页

1. 品牌导航：时效总览、柜子时效、航线时效、亚马逊仓库；提供数据说明。
2. 深色介绍区：产品价值与开船—拆柜—送仓三节点示意，明确演示数据。
3. 筛选：开船月份、起运港、目的港、公司渠道、查验；默认上一个自然月。
4. 三个视角：柜次平均开船至拆柜、最快航线平均时效、送仓批次平均开船至送仓。每个视角配近六个月图表和详情入口。
5. 主力航线：同一航线近六个月趋势，可切换均值/P90；旁边以横向条形比较各航线平均时效。
6. 仓库：横向条形比较实际送仓时效。柜子：直方图展示样本分布。

## 详情与对比

- 最多四项，支持搜索、选择、取消、应用、移除；达到上限禁选未选项。
- 对比卡片显示平均时效、P90、样本量。图形使用一致的 60 天尺度，超过范围截断，确切值以数字为准。
- 分段堆叠图始终展示全程，避免切换子指标后误读分段总和。
- 历史图与分布图随所选指标变化。柜子详情用实际日期时间线代替没有意义的单柜跨月曲线。
- 航线/仓库换月保留选择，无数据不填零。柜子选择随筛选重新初始化。
- 图表悬浮显示具体数值；排行可点击进入或添加对比。

## 已覆盖的状态

桌面、手机、窄屏；默认月份；筛选命中/互斥；空月份；对比项无数据；四项上限；搜索无结果；取消未应用的选择；单柜检索；数据口径说明；返回与浏览器后退。

## 后续接入范围

当前只做对外前台设计稿，不包含管理后台、账号登录、生产 API、发布审批或云端部署。后续接口应明确统计时间基准、有效分母、未完成样本量、按指标有效性、权限与发布状态，再替换模拟数据适配层。
